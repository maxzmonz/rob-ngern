รหัสนี้เป็นกุญแจสมุด ใครมีรหัสจะเปิดและแก้ข้อมูลได้ เก็บไว้ส่วนตัว หากไม่มีทั้งรหัสและเครื่องเดิม จะเปิดข้อมูลออนไลน์เดิมไม่ได้

ปฏิทินรับเงินทุก 6 วัน

วันตามแผนไม่เพิ่มรายรับเอง และไม่ล็อกจำนวนรอบต่อเดือน

เพิ่มบนหน้าจอมือถือ

ติดตั้งเป็นเว็บแอป เปิดได้จากไอคอนเหมือนแอปทั่วไป

  1. Android: เปิดด้วย Chrome → เมนู ⋮ → ติดตั้งแอป หรือเพิ่มลงในหน้าจอหลัก
  2. iPhone: เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดเป็นเว็บแอป (ถ้ามี) → เพิ่ม

นี่คือไอคอนเปิดเว็บแอป ยังไม่ใช่วิดเจ็ตแสดงยอดบนหน้าจอโดยไม่เปิดแอป วิดเจ็ตแบบนั้นต้องมีแอปหรือส่วนเสริมของระบบมือถือ

ถ้าเปิดจากไอคอนแล้วข้อมูลว่าง ให้เชื่อมด้วยรหัสเดิม พื้นที่เก็บของเบราว์เซอร์กับเว็บแอปอาจแยกกัน

ยอดตั้งต้นก่อนเริ่มบันทึก ＋

ใส่ยอดก่อนรายการแรก ไม่ใส่ยอดปัจจุบันบวกประวัติเก่าซ้ำ ช่องค่าผ่อนใช้กับบิลที่เลือกหนึ่งใบ ถ้ามีหลายบิลให้เริ่มด้วยยอดเงินใช้จ่ายรวมแล้วค่อยย้ายแยกรายบิลตามจริง

สำรองและกู้คืน

ไฟล์ JSON เป็นสำเนาข้อมูล ไม่รวมรหัสลับเชื่อมเครื่อง เก็บไฟล์ในที่ส่วนตัว

เมื่อต่อสมุดออนไลน์ การกู้คืนจะแทนข้อมูลของสมุดนั้นในทุกเครื่องหลังยืนยัน และย้อนกลับล่าสุดได้

วิธีคำนวณและใช้งาน ＋

กันตามรายบิล: เงินที่บิลยังขาด ÷ จำนวนรอบรับเงินก่อนวันครบกำหนด รวมเงินรอบที่กำลังบันทึก ไม่อาศัยเงินที่จะเข้าวันเดียวกับวันจ่ายล่วงหน้า ถ้าได้รับเงินจริงในวันครบกำหนดแล้ว เงินรอบนั้นนำมากันได้ เรียงวันจ่ายใกล้ก่อนและไม่กันเกิน 1,500 บาทรวมทุกรอบ

บิลต้นเดือนถัดไปเริ่มกันได้จากเดือนนี้ เพิ่มแต่ละงวดที่ทราบไว้ล่วงหน้า เงินคาดการณ์ไม่ใช่ยอดเงินจริง หากรายรับไม่พอจะบอกส่วนที่ยังขาดโดยไม่สร้างเงินขึ้นเอง

จ่ายบิลแล้ว: หักจากกระปุกก่อน หากไม่พอจะแสดงยอดที่จะเติมจากเงินใช้จ่ายให้ยืนยัน รองรับจ่ายบางส่วน และไม่หักซ้ำเมื่อจ่ายครบแล้ว

เงินสะสม: ยอดไม่รีเซ็ตเมื่อขึ้นเดือนใหม่ เงินใช้จ่าย + เงินเก็บ + กระปุกบิลที่ยังมีอยู่ = เงินทั้งหมด ย้ายเงินไม่ใช่รายรับหรือรายจ่าย ส่วนพ่อจ่ายให้เป็นสถิติแยก

ข้ามเครื่อง: กดสร้างสมุดออนไลน์ที่เครื่องเดิม เก็บรหัส แล้วกรอกรหัสที่เครื่องใหม่ สมุดจะซิงก์เมื่อเปิดแอปและเมื่อบันทึก ถ้าอินเทอร์เน็ตขาด รายการล่าสุดจะเก็บรอในเครื่องและแสดงสถานะชัดเจน ต้องซิงก์รายการนั้นก่อนบันทึกเพิ่ม หากสองเครื่องแก้พร้อมกันจะให้เลือกฉบับที่ต้องการและเก็บสำเนาทั้งคู่ก่อน

การติดตั้งบนมือถือช่วยเปิดเร็วและเปิดหน้าจอที่เคยโหลดไว้ได้ขณะออฟไลน์ กราฟหรือฟอนต์จาก CDN อาจไม่พร้อมจนกว่าจะออนไลน์ การซิงก์ต้องเชื่อมอินเทอร์เน็ต
